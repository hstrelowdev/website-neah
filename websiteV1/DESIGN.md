## Brand & Style

This design system translates the kinetic structure of software delivery into an interface foundation. Built around "The Commit Line" concept, it treats interfaces as living version graphs: sequential milestones, branching flows, and deterministic runtime states. The aesthetic bridges high-performance IDE engineering with refined developer-tool elegance.

### Target Audience & Core Persona
Engineers, devops leads, and platform architects who evaluate software through precision, density, performance, and transparency. The visual language conveys speed, deterministic logic, and absolute zero-latency feedback.

### Visual Style
A hybrid of **Technical Modernism** and **Tactile Glassmorphism**:
- **Deep Navy canvas** provides a low-strain, high-focus backdrop.
- **Translucent surfaces** layered with hairline borders mimic illuminated glass plates.
- **The Commit Line**: Continuous vertical and horizontal conduits with illuminated nodes (Emerald, Teal, and Royal Blue) linking processes, steps, and system logs.
- **Dot-matrix lattices** and subtle circuit grids reinforce spatial alignment without visual clutter.

## Colors

The palette revolves around deep optical contrast, moving from deep space navy into vibrant, illuminated spectrums of blue, cyan, and emerald.

### Primary Spectrum
- **Deep Navy (`#0B1F3F`)**: Foundational base, root canvas, and elevated structural layers.
- **Royal Blue (`#2F6BFF`)**: Primary actions, high-priority interactive states, active commit lines.
- **Teal (`#12B5B0`)**: Secondary pathways, telemetry data, active branch states, interactive hover stages.
- **Emerald (`#22C58B`)**: Deployment success, production markers, operational commit nodes, live telemetry pulses.
- **Pale Blue (`#EEF6FB`)**: High-contrast metadata badges, light surface fills, and primary labels on dark accents.
- **Pure White (`#FFFFFF`)**: Headline text, top-level contrast, and active code readouts.

### Signature Gradient & Transitions
- **The Commit Gradient**: Linear `135deg` from `#2F6BFF` via `#12B5B0` to `#22C58B`. Reserved for pipeline progression lines, primary interactive focus boundaries, and active deployment states.
- **Dark Neutral Derivatives**:
  - `Surface 00`: `#07152B` (Root viewport, canvas)
  - `Surface 01`: `#0B1F3F` (Primary cards, sidebars, panes)
  - `Surface 02`: `#11284E` (Interactive cards, nested containers)
  - `Surface 03`: `#183565` (Floating panels, popovers)

## Typography

The type hierarchy combines technical authority with structural precision.

- **Display & Headings (Space Grotesk)**: Geometric, confident, and slightly eccentric. Its technical nuances echo mechanical drafts and early aerospace telemetry, giving headers a forward-thinking presence.
- **Interface & Content (Inter)**: The operational workhorse. Utilized for documentation, descriptions, tabular entries, and long-form data due to its neutral texture and legibility on luminous displays.
- **Code & Micro-labels (JetBrains Mono)**: Strictly applied to commit hashes, Git references, terminal streams, branch tags, latency figures, and technical metadata.

## Layout & Spacing

The spatial architecture balances density with visual clarity, ensuring deep analytical screens remain parseable.

### Grid Engine
- **Desktop (>= 1280px)**: 12-column fluid grid. Outer margins set at `margin-desktop` (3rem) with `gutter-lg` (2rem) between major columns.
- **Tablet (768px - 1279px)**: 8-column layout. Margin set at `margin` (2rem), gutter at `gutter` (1.5rem). Split-screen side panels collapse into drawer overlays or bottom sheets.
- **Mobile (< 768px)**: 4-column layout. Margin reduced to `margin-mobile` (1rem), gutters clamped to `gutter-sm` (1rem).

### Layout Rules
- **The Commit Axis**: A persistent 2px vertical rail down tree views, step wizards, and activity feeds. Nodes snap directly to a 4px horizontal sub-grid to ensure zero visual misalignment with adjacent typography.
- **Density Scaling**: Component internal padding stays tight (`space-xs` to `space-md`) within data structures, letting containers breathe via `space-lg` and `space-xl` separators.

## Elevation & Depth

This system avoids flat gray overlays, instead using ambient dark blue backdrops, blurred glass panels, and selective luminosity.

### Layering Model
- **Level 0 (Canvas)**: Solid `#07152B` overlaid with a subtle SVG dot-matrix grid (`radial-gradient(rgba(47, 107, 255, 0.15) 1px, transparent 1px)`, 24px spacing).
- **Level 1 (Structural Panes)**: Background `#0B1F3F` at 70% opacity with `backdrop-filter: blur(16px)`. Rimmed by a 1px border: `rgba(255, 255, 255, 0.08)`.
- **Level 2 (Active Cards & Flyouts)**: Background `#11284E` at 85% opacity with `backdrop-filter: blur(24px)`. Rimmed by a 1px border: `rgba(18, 181, 176, 0.3)`.
- **Level 3 (Modals & Tooling Drawers)**: Deep `#0B1F3F` with an omni-directional ambient shadow: `0 24px 48px -12px rgba(2, 8, 20, 0.8), 0 0 24px 0 rgba(47, 107, 255, 0.12)`.

### Chromatic Glow
Accent elements (active nodes, primary switches, deploy triggers) emit localized glows via soft box-shadows:
- **Deploy/Success Pulse**: `0 0 16px rgba(34, 197, 139, 0.45)`
- **Commit/Pipeline Active**: `0 0 16px rgba(47, 107, 255, 0.5)`
- **Teal Focus/Branching**: `0 0 16px rgba(18, 181, 176, 0.45)`

## Shapes

The design uses balanced curves to balance technical precision with modern software elegance.

- **Base Radius (`0.5rem` / `8px`)**: Applied to badges, inputs, table rows, micro-cards, and tooltips.
- **Large Radius (`1rem` / `16px`)**: Standard for content containers, terminal panes, metrics cards, and pipeline run stages.
- **Extra Large Radius (`1.5rem` / `24px`)**: Applied to top-level terminal envelopes, main navigation wrappers, and floating modals.
- **Terminal Windows**: Top window header uses integrated asymmetric fillets with minimal macOS-style control nodes (colored with subtle `#0B1F3F` internal rims).
- **Commit Nodes**: Strictly circular (`50%` radius / fully round) with an internal concentric core dot to resemble genuine git graph commits.

## Components

### Buttons
- **Primary**: Background filled with the signature gradient (`#2F6BFF` to `#12B5B0`), text `#FFFFFF`, font `Space Grotesk` (semi-bold). Box shadow: `0 4px 14px rgba(47, 107, 255, 0.3)`. On hover, scale 1.01 with expanded glow.
- **Secondary (Glass)**: Background `rgba(47, 107, 255, 0.08)`, border `1px solid rgba(18, 181, 176, 0.4)`, text `#EEF6FB`. On hover: `rgba(47, 107, 255, 0.16)` with border `rgba(18, 181, 176, 0.8)`.
- **Tertiary / Ghost**: Transparent base, text `#12B5B0`, hover background `rgba(255, 255, 255, 0.04)`.

### The Commit Line (Graph & Nodes)
- **The Rail**: A 2px solid line passing vertically or horizontally through stages. Default state: `rgba(255, 255, 255, 0.1)`. Active/Passing state: signature gradient (`#2F6BFF` -> `#12B5B0` -> `#22C58B`).
- **Nodes**:
  - *Pending*: 12px ring, 2px border `#2F6BFF`, interior transparent.
  - *In Progress*: 12px ring with a breathing pulse ring (`animation: ping 1.5s cubic-bezier(0, 0, 0.2, 1) infinite`) in `#12B5B0`.
  - *Success / Master Commit*: 12px filled dot `#22C58B` with a `#FFFFFF` concentric 4px center dot.

### Terminal Windows
- Multi-pane console wrapper with `1.5rem` radius. Header contains status indicators, branch label (`JetBrains Mono`), and execution latency.
- Interior base uses `#07152B`, typography uses `JetBrains Mono` (`13px`, `#EEF6FB`), with line numbers styled in `rgba(238, 246, 251, 0.3)`.

### Chips & Tech Badges
- Height: `24px`. Roundedness: `0.5rem`.
- Monospaced typography (`JetBrains Mono`, `11px`).
- Background: `rgba(11, 31, 63, 0.8)`, border: `1px solid rgba(255, 255, 255, 0.1)`. Left-hand accent indicator: 6px solid dot reflecting status color.

### Form Inputs & Fields
- Height: `40px`. Padding: `0 12px`.
- Background: `rgba(7, 21, 43, 0.6)`, border: `1px solid rgba(255, 255, 255, 0.12)`.
- Text: `#FFFFFF`. Placeholder: `rgba(238, 246, 251, 0.4)`.
- Focused: Border `1px solid #12B5B0`, shadow `0 0 0 3px rgba(18, 181, 176, 0.2)`.

### Checkboxes & Radio Controls
- Base: 16px square or circle with `1px solid rgba(255, 255, 255, 0.2)` on `rgba(11, 31, 63, 0.6)`.
- Selected: Background `#2F6BFF` or `#22C58B` with an inset Pure White mark and glow.

### Cards & Dashboards
- Glassmorphic panels with subtle directional light: `linear-gradient(180deg, rgba(255,255,255,0.06) 0%, rgba(255,255,255,0) 100%)` layered over `rgba(11, 31, 63, 0.7)`.
- Border highlight: 1px top border `rgba(255, 255, 255, 0.15)`, side/bottom border `rgba(255, 255, 255, 0.05)`.
